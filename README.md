# CIRNET Hardware

[English documentation](docs/en/index.md) · [Tài liệu tiếng Việt](docs/vi/index.md)

The Rust service implements local Hardware RPC 2.0 and supervises the C++ Simulator worker. It exposes virtual stations and preserves guarded Start, safe Stop and quarantine reporting.
